# Hello World
Hides 16 bits (2 bytes) in a text saying Hello World using Steganography.

## Download
You can download it from [here](https://github.com/PhasedGapple/Hello-World/releases/tag/R).
If you encounter any undisclosed issues, please open a issue on the issues page.
## Usage
To hide the bits, get any 16 bit number (like 1010000001010000) and pass ``encrypt NUMBER`` as an argument when opening the app. Replace NUMBER with 16 bits.
To recover the bits, pass ``decrypt "TEXT"`` as an argument. Do NOT forget the "" else it wont work.
