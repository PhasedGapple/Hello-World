# Hello World
Hides 16 bits (2 bytes) in a text saying Hello World using Steganography.
<img width="1131" height="671" alt="image" src="https://github.com/user-attachments/assets/c4837ce8-da20-43dd-b6b7-a02c191729df" />

## How does it work?
It works by replacing some of the letters to almost identical letters which arent the same. Each replacement letter has its own bit value, for example "𝖽" has a value of 11 (in bits)
